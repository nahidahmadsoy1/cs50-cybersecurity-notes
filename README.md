## Course Overview

This repository acts as a personal knowledge base covering fundamental concepts in cybersecurity, including network defense, identity authentication, cryptography, memory safety, and web application security.

---

## Week 1: Introduction to Cybersecurity

* **Core Focus:** Fundamental concepts of security, threats, and risks.
* **Key Topics:**
  * **CIA Triad:** Confidentiality, Integrity, and Availability.
  * **Threat Actors & Vectors:** Understanding how systems are targeted.
  * **Basic Network Security:** IP addresses, routers, and firewalls.

---

## Week 2: Securing Accounts & Identity

* **Core Focus:** Authentication mechanisms, credentials, and access control.
* **Key Topics:**
  * **Authentication Factors:** Something you know, something you have, something you are.
  * **Multi-Factor Authentication (MFA):** Adding defensive layers against unauthorized access.
  * **Password Hygiene:** Hashing passwords, salt values, and avoiding dictionary attacks.

---

## Week 3: Securing Data & Cryptography

* **Core Focus:** Protecting data at rest and data in transit using cryptographic techniques.
* **Key Topics:**
  * **Symmetric Encryption:** AES encryption using a shared single key.
  * **Asymmetric Encryption:** Public and Private key infrastructure (RSA/ECC).
  * **Hashing & Integrity:** SHA-256 for integrity verification and digital signatures.
  * **VPNs & Secure Protocols:** TLS/SSL, HTTPS, and secure data transit.

---

## Week 4: Securing Software

* **Core Focus:** Defensive programming, vulnerability management, and memory safety.
* **Key Topics:**
  * **Buffer Overflow:** Memory safety flaws and avoiding array bounds violations.
  * **Input Validation & Sanitization:** Treating external user input as untrusted.
  * **SQL Injection (SQLi):** Preventing database manipulation using Parameterized Queries.
  * **Cross-Site Scripting (XSS):** Escaping output and securing client-side web scripts.
  * **Principle of Least Privilege:** Restricting execution permissions to minimum requirements.
